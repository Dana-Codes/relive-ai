# ReLive AI

> Transform your reality. Live.

ReLive AI is a real-time AI video transformation platform for creators.

The platform allows users to transform their live camera feed using generative AI and eventually stream the transformed output to platforms such as YouTube, Twitch, and TikTok.

## Vision

Build a production-grade real-time AI video platform that combines:

- Real-time video processing
- Generative AI
- WebRTC
- Live streaming
- Creator tools
- Usage-based billing
